# DW-Metro-CDMX

Sistema analítico y Data Warehouse para la evaluación de afluencia y tiempos de retraso en la red del Metro de la CDMX.

## Estructura del Repositorio
* `scripts/`: Pipeline ETL en Python para la extracción, limpieza e integración de datos.
* `data/`: Modelo dimensional (Tablas de Hechos y Dimensiones) exportado en formato CSV para IBM Cognos Analytics y MySQL.
* `docs/`: Documentación técnica del proyecto, esquema en copo de nieve y vistas del Dashboard.
